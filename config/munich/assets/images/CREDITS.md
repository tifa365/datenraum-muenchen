## Obligations for CC BY-SA images

Wherever `muenchen-parking-salvatorgarage*.jpg` is shown, display a visible credit next to it, e.g.

> Foto: Henning Schlottmann (H-stt), [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0), via [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Salvatorgarage_7174.jpg), zugeschnitten

The API delivers this text as `image.attribution` with `image.attributionRequired: true`.
Share-alike applies to the image files only, not to the dashboard code.
